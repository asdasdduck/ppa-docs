Getting Started

Most tuning can be done in-game. Start with one change, apply it, and watch the result before adjusting more.

Find the Menus

With SKSE Menu Framework installed, open its menu and choose Procedural Penis Animations. PPA has four pages:

PageWhat to change
GeneralOpening physics, butt physics engine, actor filters, expressions, language, hotkeys, and debug views.
Sound EffectsClap/wet timing, volume, pitch, rumble, and legacy CBPC impulses.
Body ProfilesPenis size and detection, openings, hands, belly bulge, and built-in butt physics. Pick a config at the top.
ExpressionsFacial presets, conditions, and morph effects for the selected config.

Dimmed body-profile fields match the inherited value. Changed fields show a dot. Hover a setting for a short explanation.

To change how an opening moves, go to Body Profiles → Orifices and adjust its opening offsets. To move the entrance or internal path, use the orifice editor.

Body Profiles and Expressions can edit the default config and single-override files. A file marked read-only contains multiple overrides; edit its TOML directly.

Language

Choose an installed language under General → Locale → Language, save, then restart Skyrim. English is the default. Missing translations stay in English.

Make a Translation

Click Dump under Locale to write Data/SKSE/Plugins/ppa-translations/english.json. Copy it to a name like german.json and translate the values on the right:

{
    "General": "Allgemein",
    "Sound Effects": "Soundeffekte"
}

Keep the keys on the left unchanged, including any ||context suffix. Keep placeholders such as {} and %s in the translated text. Save as UTF-8, select the new language, and restart.

You can also set Language = "german" under [General] in the main TOML. Use the filename without .json.

Apply, Save & Revert

Use the buttons at the top of a settings page:

ButtonResult
ApplyTry the edits for this game session without writing the file.
SaveApply the edits and write them to the config file.
RevertReturn the selected file to its saved settings, including discarding session-only edits.

With Auto-save enabled, closing the mod menu saves edits you have not applied yet. With it disabled, closing applies them without saving. A change marked Applied, not saved still needs Save to keep it for your next game session.

Example: lower butt Strength, click Apply, and watch a scene. Click Save if you like it, or Revert to restore the saved file.

Animation targets have their own Save Changes button. The orifice editor also has its own Save menu.

Hotkeys

These are the shipped bindings. Existing configs may use different keys; check General → Hotkeys.

ActionDefault
Select actor / open target editorBackspace (SelectActor = 14)
Reload settingsF5 (Reload = 63)
Toggle PPA physicsF2 (Pause = 60)
Speed up / slow down animationUnbound; assign keys in the menu.

If HotkeyWhileHoldingShiftOnly is enabled, hold Shift too. ConsoleOnly restricts Reload and Pause to a paused UI, such as the console.

Fix an Animation’s Target

  1. Start a supported SexLab or OStim scene and look at an actor.
  2. Press your Select Actor key to open the target editor.
  3. Choose the Performer whose penis needs adjusting, then the Target Actor.
  4. Choose the stage range and an action, such as Anus or Left Hand.
  5. Watch the change, then click Save Changes to keep it.

You can also click a highlighted shaft to choose the performer, then an opening or hand to choose its recipient and action. Auto Detect restores automatic selection; None disables that performer’s tracking for the chosen stages.

Example: if actor 2 should target actor 1’s anus in stage 3, select performer 2, target actor 1, stage 3, then Anus. See Animation Action Tags for JSON examples.

PPA skips alignment for off-screen actors when Skyrim stops updating their full animation pose. Bring the scene back into view if alignment stops.

Move an Opening or Internal Path

Look at the actor, press Select Actor, and choose Edit Orifices. Pick Vagina, Anus, or Mouth. The editor enters free camera and lets you move the entrance or a waypoint along the internal path.

ControlAction
Arrow keysMove the selected point left/right and up/down.
ShiftToggle up/down movement to forward/back.
− / +Change the point-movement step.
Mouse wheelChange free-camera speed.
EnterTemporarily apply the path to the actor’s active scene.
Tab or Select Actor keyOpen the editor menu to choose points, add/remove a waypoint, or save.
EscapeExit the editor.

When saving, choose Save to actor’s current config to update the selected source file, or Create new overlay config for an NPC-specific adjustment. Editing a shared source can affect other actors using it.

The NPC option writes ppa-override-configs/000-ppa-npc-*.toml. It matches the actor’s base ID, so it also affects other references of that NPC base. Delete the overlay and reload to remove it.

If the mouth entrance is correct but the lips open too late, adjust InsertionLead instead.

Edit Config Files

All folders below are under Data/SKSE/Plugins/ in your Skyrim installation.

PathContents
accurate-penetration.tomlGlobal settings and default body, expression, and sound settings.
ppa-override-configs/*.tomlBody/race/NPC settings and overlays.
ppa-animation-tagging/*.jsonAnimation targets by stage and actor position.
ppa-sound-effect-configs/*.tomlSound lists and legacy CBPC impulse overrides.
ppa-voice-configs/*.tomlVoice packs, conditions, timing, and lip sync.
ppa-translations/*.jsonMenu translations. See Language.

Examples on the reference pages show either a complete override file or fields to edit in an existing table. In TOML, add a setting under its matching section; do not create a second copy of the same table. Keep decimal values as decimals, such as 1.0.

After hand-editing body or sound settings, use Reload. For voice edits, reload during a tracked scene or restart Skyrim. For JSON edits, see the target reload notes.
